## Biggest challenge
My biggest challenge was getting the ViewModel to work with the Compose preview and testing the profile icons. 
The preview kept breaking because the ViewModel expected live data, which previews don’t provide. 
I had to learn how to give the preview fake/default data and separate UI logic from the ViewModel. 
Once I figured that out, testing and previews became much easier.

## Most valuable thing I learned
The most valuable thing I learned was how to be patient while working in a new language and how to read and understand other people’s code.

and logic. Learning to read their code helped me understand how to write my own. Overall, I learned a lot about adapting to a 
new language and improving my ability to learn from others.
